# 12 inch waterjet medallion

White = retained plate. Black = through-cut.

Sized for a **12 inch** (304.8 mm) circular plate on a 12"×12" blank. The
artwork keeps a broad “everywhere” travel set as bold silhouettes, and the
quote uses open stencil letterforms so characters like **E** keep cut detail
instead of collapsing into solid blobs.

## Fabrication files

- `waterjet-ready.dxf` — primary AutoCAD R12 geometry in millimetres.
- `waterjet-ready.svg` — equivalent closed geometry for Fusion 360.
- `parts/` — optional aligned part exports if generated by the builder.

Cut `CUT_INNER` first, then `CUT_OUTER`. Kerf, lead-ins, and pierce strategy stay in CAM.

## Rebuild

```sh
python3 scripts/build_waterjet_artwork.py \
  fabrication/waterjet/waterjet-source-12in.png \
  --output-dir fabrication/waterjet \
  --diameter-mm 304.8 \
  --silhouette-open-mm 0.5 \
  --silhouette-close-mm 0.65 \
  --minimum-cut-area-mm2 10 \
  --minimum-cut-width-mm 1.6 \
  --support-width-mm 2.5 \
  --minimum-island-area-mm2 6 \
  --simplify-mm 0.4 \
  --threshold 155
```
